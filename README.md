# 🎯 About the Project

**Kalangan Art Café** is a cultural space where creativity meets chai. The café revives local craftsmanship and creates a welcoming community hub for artists, makers and visitors.

This website presents the café's identity, art products, menu, and upcoming workshops, giving visitors one place to explore everything Kalangan offers.

---

# ✨ Features

- 🏠 Hero landing page with image slider and tagline
- 🛍️ Shop section featuring handmade crafts, art mugs and canvas prints
- ☕ Dual menu: a **Café Menu** and an **Art Menu**
- 🎭 Workshops & events page for weekend sessions led by artisans
- 📖 About page sharing the café's story and mission
- 📬 Contact page with feedback form
- 🔐 Sign In and Log In pages
- 📍 Embedded Google Maps location
- 📱 Responsive layout styled with Tailwind CSS
- 🔗 Social media links in the footer

# ⚙️ Run Locally

## 1. Clone the Repository

```bash
git clone https://github.com/Shreyashg07/Kalangan-art.git

cd Kalangan-art/frontend
```

## 2. Open the Site

Simply open `index.html` in your browser.

Or serve it with a local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

---

# 🚀 Deploy to Render

1. Push the repository to GitHub.
2. In Render, choose **New → Static Site** and connect the repository.
3. Set the **Publish Directory** to `frontend`.
4. Leave the build command empty (no build step is required).
5. Click **Create Static Site**.
